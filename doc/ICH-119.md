## Safety requirements for this port

The upstream snapshot is not safe to import unchanged. The port must:

- Apply file masks and search-template conditions together; the upstream
  callback can otherwise admit files excluded by either filter.
- Publish actions only after a complete, successful comparison. Failed
  listings and cancellation must not turn an unknown directory into an
  empty one.
- Keep physical child counts separate from the displayed selection and
  avoid descending through directory symlinks.
- Honor the confirmed copy/delete directions for directories as well as
  files. Create parents before copying children; remove directories only
  after file operations, from deepest to shallowest.
- Recheck physical emptiness before deleting a directory. Excluded files
  and files added after comparison must survive.
- Stop subsequent operations after failed creation, copying or cancellation.
  Immediate deletion must not update the model merely because deletion
  was requested.
- Keep hierarchical actions within actual ancestor/descendant paths,
  including sibling names such as `a` and `a-`.
- Consult copy support in both directions and compare the two source
  instances, rather than comparing a source with itself.
- Rescan and notify both compared roots after operations, including partial
  failures, so existing Tree File View refresh can rebuild expanded rows.

### Deliberately excluded

- The separate verification checkbox (`e7236ed9e`) and directory-selection
  theme setting (`b6a9d9914`). Existing selection colors are sufficient.
- A full archive-layer merge from ICH-118.
- Upstream directory metadata helpers with unchecked copy-in results.
  Empty-directory creation must use checked operations; replicating their
  timestamps and attributes is not part of this port.
- Remote-to-remote synchronization requiring temporary file transfer.
- Native Wayland input/focus claims based only on offscreen tests.

### Backend safety limits

- WFX and Windows Shell synchronization is declined: their listing APIs do
  not currently give this port a reliable complete-enumeration signal.
  Browsing and ordinary operations on those sources are unchanged.
- Empty-directory removal uses non-recursive filesystem `rmdir` or GIO
  `g_file_delete`. WCX directory deletion is declined with a warning:
  its recursive wildcard could remove children created after comparison.
  WCX file transfer, including empty-directory creation, remains supported.
- Listing errors and skipped copies stop synchronization before subsequent
  destructive operations. `AbortOnSkip` is enabled only for synchronization
  copies, not ordinary copy operations.
- Linux enumeration clears libc's errno before `readdir64`, matching the
  errno getter; an unrelated earlier error must not invalidate a full listing.
- Asymmetric mode mirrors the left side, including replacement of a newer
  right-side file. "Only selected" refers to the panels' top-level selection;
  selecting a directory includes its descendants.

## Validation

Completed on Linux x86-64, FPC 3.2.2, Lazarus 4.8 and Qt6:

- Baseline components/application build and final complete Release build.
  The final build linked successfully with 208 warnings, including the
  existing `crtbeginS.o` and `crtendS.o` search warnings.
- Core regression: all 15 groups passed, including timestamp direction,
  asymmetric replacement/deletion, empty directories/counts, direction flags,
  masks and selection, late children, failed operations, Skip/SkipAll,
  incomplete/aborted scans, symlinks, hierarchy, sorting and source identity.
- Real GIO `file://` synchronization in both directions, empty directories
  and non-recursive deletion using source paths and full URIs.
- Installed WCX ZIP plugin: real comparison and synchronization into/out of
  a disposable ZIP, empty-directory creation and missing-parent CopyIn.
- Real dialog, offscreen: masks/templates, sorting, resizing, action commands,
  space toggle, saved empty-directory option, synchronization confirmation
  and automatic refresh of already-expanded Tree File View rows.
- Existing file-source regression: filesystem existence/mapping, unsupported
  sources, mounted paths and stash lifetime/notifications.
- Dedicated regression reproducing stale libc errno at directory-list EOF.
- Project XML/JSON parsing, Markdown lint and Git whitespace checks.

### Build

From the worktree root:

```sh
lcl=qt6 ./build.sh components
(
  cd src
  lazbuild --skip-dependencies --build-all --ws=qt6 \
    --build-mode=release doublecmd.lpi
)
```

The baseline components and application compiled with FPC 3.2.2 and
Lazarus 4.8 on Linux x86-64. A separate resource check confirmed that the
embedded `HIGHLIGHTERS` and `DOUBLECMD` data exactly match the tracked inputs,
despite relative-resource diagnostics from a root-directory build.
Use complete rebuilds to avoid the previously observed FPC incremental
compiler exception with circular application-unit dependencies.

### Regression program

```sh
mkdir -p "$HOME/.pi/agent/tmp"
scratch=$(mktemp -d "$HOME/.pi/agent/tmp/ich119-test.XXXXXX")
lazbuild --skip-dependencies --build-all --ws=qt6 \
  tests/syncdirs_regression.lpi
QT_QPA_PLATFORM=offscreen \
  ./units/x86_64-linux-syncdirs-tests/syncdirs_regression \
    --config-dir="$scratch"
```

To include WCX, provide `ICH119_ZIP_PLUGIN` and `ICH119_ZIP_ARCHIVE`.
The archive must be a **disposable writable fixture**, not user data:

```sh
printf 'fixture\n' > "$scratch/seed.txt"
(cd "$scratch" && zip -q fixture.zip seed.txt)
ICH119_ZIP_PLUGIN=/opt/doublecmd/plugins/wcx/zip/zip.wcx \
ICH119_ZIP_ARCHIVE="$scratch/fixture.zip" QT_QPA_PLATFORM=offscreen \
  ./units/x86_64-linux-syncdirs-tests/syncdirs_regression \
    --config-dir="$scratch"

mkdir "$scratch/gui" "$scratch/filesource"
lazbuild --skip-dependencies --build-all --ws=qt6 \
  tests/syncdirs_dialog_regression.lpi
QT_QPA_PLATFORM=offscreen \
  ./units/x86_64-linux-syncdirs-dialog-tests/syncdirs_dialog_regression \
    --config-dir="$scratch/gui"
lazbuild --skip-dependencies --build-all --ws=qt6 \
  tests/filesource_regression.lpi
QT_QPA_PLATFORM=offscreen \
  ./units/x86_64-linux-tests/filesource_regression "$scratch/filesource"
```

Use disposable fixtures and an isolated configuration. Assertions must cover
the real synchronization model, services and dialog, not a duplicate
implementation. Keep failure logs for diagnosis; remove task-owned fixtures
and logs when no longer needed.

### Remaining environment-dependent checks

- FTP/Samba require a disposable server and credentials. Local GIO and ZIP
  tests do not prove remote protocol behavior.
- Windows and macOS builds/runtime behavior require those platforms.
- Native Qt6/Wayland focus, mouse input and menu presentation require an
  interactive session; offscreen event-handler tests do not replace it.

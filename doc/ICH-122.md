# ICH-122: standalone functional fixes

## Scope

- Issue: <https://linear.app/ichelema/issue/ICH-122>
- Original repository: <https://github.com/doublecmd/doublecmd>
- Fork: <https://github.com/ichelema/doublecmd>
- Fork baseline: `7a3ac180c`.
- Upstream reviewed through `69a686c3c`.

This is a selective integration, not an upstream branch merge. Archive,
synchronization, platform, theme and translation work remains in its own
issues. The fork's Tree File View and Qt6/Wayland workarounds must remain.

## Selected fixes

- **Search history:** `1712e6994`. Reset the Qt combobox selection after
  changing its history, so the next search does not use the previous text.
  Apply the reset to insertion as well as moving an existing entry: the
  regression test reproduces both cases on Qt6.
- **YAML highlighter:** `c054b8e49`. Do not skip past the line terminator
  after a backslash. Instead of restricting escape handling to quotes, keep
  the existing handling of escaped backslashes and guard the line boundary.
- **Inactive tabs:** `bf9c7598f`. Preserve a delayed tab's saved path when
  its removable drive or network directory is temporarily unavailable.
  Import only the delayed-loading guard, not the optional `?` tab marker
  and its settings. Activation keeps an unavailable path; navigating to
  `..` uses the existing fallback to an available parent.
- **Main-command dialog:** `da9b05640`. Populate the categories when no
  previous command is available.
- **WLX Quick View focus:** `9f2324b08`, `25b194692`. Return focus to the
  file-list control on mouse-down under Qt5, Qt6 and GTK3, as on Windows.
- **Opus duration:** `db2e8c114`. Use the fixed 48 kHz granule clock and
  subtract the pre-skip; do not divide by the original input sample rate.
- **Unicode multi-rename:** `2844f206c`. Interpret negative `[N]` positions
  as character offsets rather than UTF-8 byte offsets.
- **Thumbnail scrolling:** `b6dcb2b6e`. Scroll by one thumbnail row per
  wheel event instead of applying text-row scrolling.
- **Command-line navigation:** `96445dec1`, `4216cb019`, `e7ede7a4a`.
  When replacing an existing tab's path, select the appropriate file source
  rather than interpreting a local path inside the previously active
  virtual source. Preserve recognized virtual paths and select local files
  in their containing directory. Include the associated Windows network
  path classification correction.

## Automated checks

Build using the existing Qt6 commands:

```sh
lcl=qt6 ./build.sh components
lcl=qt6 ./build.sh doublecmd
lazbuild --ws=qt6 plugins/wdx/audioinfo/src/AudioInfo.lpi
```

The baseline and final Qt6 release builds passed with Free Pascal 3.2.2
and Lazarus 4.8 on Linux x86-64. The final AudioInfo plugin build and all
four regression programs below also passed.

For the final rebuild, `lazbuild --skip-dependencies --build-all --ws=qt6
--build-mode=release src/doublecmd.lpi` was run before the normal application
build command. Use `--build-all` for these test projects too: FPC 3.2.2
raised internal exceptions during incremental rebuilds of the application's
circular unit dependencies; complete rebuilds succeeded.

The functional regression program uses the real application units and Qt6
widgets, rather than a reimplementation of the fixes:

```sh
mkdir -p "$HOME/.pi/agent/tmp"
scratch=$(mktemp -d "$HOME/.pi/agent/tmp/ich122-functional.XXXXXX")
lazbuild --skip-dependencies --build-all --ws=qt6 \
  tests/functional_regression.lpi
QT_QPA_PLATFORM=offscreen \
  ./units/x86_64-linux-functional-tests/functional_regression \
    --config-dir="$scratch"
```

It checks consecutive history selections, new and existing entries, stored
search options, empty input, YAML line boundaries, multiline continuation,
escaped quotes and escaped backslashes, plus Unicode masks through the real
multi-rename preview grid. The test skips the unrelated hot-directory menus,
which require a main window. The original code fails the history, YAML and
Unicode checks; `[N-1]` loses the final emoji before the fix.

The saved-path test creates real Columns and Tree views in a notebook. It

build, and initialize their configuration and caches only in the supplied

### AudioInfo

The standalone checker tests the real Ogg parser and its state reset after
a failed read. On this Arch Linux installation:

```sh
mkdir -p "$HOME/.pi/agent/tmp"
scratch=$(mktemp -d "$HOME/.pi/agent/tmp/ich122-audio.XXXXXX")
fpc -Mobjfpc -Sh \
  -Fuplugins/wdx/audioinfo/src/atl -Fucomponents/doublecmd \
  -Fu/usr/lib/lazarus/components/lazutils/lib/x86_64-linux \
  -FU"$scratch" -FE"$scratch" tests/audioinfo_regression.lpr
ffmpeg -v error -f lavfi \
  -i 'sine=frequency=440:sample_rate=16000:duration=1.625' \
  -c:a libopus -b:a 64k "$scratch/opus16.opus"
ffmpeg -v error -f lavfi \
  -i 'sine=frequency=440:sample_rate=48000:duration=1.25' \
  -c:a libopus -application lowdelay -frame_duration 2.5 \
  -b:a 64k "$scratch/lowdelay.opus"
ffmpeg -v error -f lavfi \
  -i 'sine=frequency=440:sample_rate=44100:duration=1.75' \
  -c:a libvorbis -q:a 3 "$scratch/vorbis.ogg"
"$scratch/audioinfo_regression" \
  "$scratch/opus16.opus" 1.625 "$scratch/lowdelay.opus" 1.25 \
  "$scratch/vorbis.ogg" 1.75
```

The expected durations were verified against FFmpeg's decoded mono
48 kHz signed-16 PCM byte count divided by 96000. The original parser
reports 4.894500 s instead of 1.625000 s for the 16 kHz input-rate fixture,
and 1.252500 s instead of 1.250000 s for the low-delay fixture.
The fixed parser passes both, covering pre-skip values 312 and 120.
Additional Opus fixtures made from 48 kHz and 44.1 kHz inputs and the Vorbis
control passed as well. Generated fixtures and compiler outputs are
disposable and stay in the scratch directory.

## Interactive regression cases

Use disposable data and an isolated application configuration. Run the
viewer and dialog cases under Qt6/Wayland, with both Columns and Tree views
where applicable. Offscreen checks do not establish native Wayland focus
behavior or freedom from interactive input-grab freezes.

1. **Find Files:** search for two different names and contents; repeat the
   first search from history, then enter a new term. Results must correspond
   to the current term, with no previous-query results.
2. **YAML:** open and scroll valid files with escaped quotes/backslashes and
   incomplete quoted values ending in a backslash. Try a continuation line,
   empty lines, CRLF and LF files. The viewer/editor must not crash or hang.
3. **Tabs:** save several active/inactive tabs, including Tree view, on a
   temporary mount or directory. Make one inactive path unavailable, restart
   with delayed tab loading, and save again without activating it. The saved
   path must remain unchanged. Restore the directory and activate the tab.
   Also check eager loading and active unavailable tabs.
4. **Commands:** open `cm_DoAnyCmCommand` with an empty `LastDoAnyCommand`;
   categories and commands must be populated. Select a command, reopen the
   dialog, and verify the existing selection and filtering still work.
5. **WLX Quick View:** focus a real WLX plugin, then click the opposite
   file-list panel. Keyboard navigation must work in that panel. Repeat
   entering/leaving the plugin and clicking expanded Tree rows.
6. **Delete dialog:** select short, long, Unicode and multiline filenames,
   individually and together. Check wrapping, visible buttons and alignment,
   then cancel; no data needs to be deleted.
7. **Fork safeguards:** expand nested Tree directories, refresh after an
   external change, switch views, and perform copy/move/drag-and-drop with
   disposable files. Open Options and check for Wayland input-grab freezes.
8. **Multi-rename:** preview masks `[N-1]`, `[N-3,2]`, `[N-3:-1]` and
   `[N2:-1]` on ASCII, accented, CJK and emoji filenames. Negative offsets
   count characters, and positive/reversed ranges must keep working.
9. **Thumbnails:** scroll a directory spanning several thumbnail rows.
   Each wheel event moves one row; verify both directions and boundaries.
10. **Command-line navigation:** with an existing tab on Stash or another
    virtual source, send a local directory and a local file to the running
    instance. Verify filesystem source selection and the selected file.
    Also test a registered virtual URI and both left/right panel options.
    On Windows, distinguish drive-letter paths from UNC servers and shares.

These interactive cases are verification instructions, not claims that a
real WLX plugin or native Wayland session has been exercised automatically.
